# Estudos_2026 Desenvolvimento de Fronted

## Primeiro Portfólio Web

Este repositório contém a primeira versão do meu portfólio pessoal. O projeto representa o meu **primeiro passo no desenvolvimento front-end**, criado para consolidar os fundamentos da construção de páginas web.

---

###  Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout e responsividade.

---

### Principais Aprendizados
- Estruturação semântica de elementos web.
- Conceitos de box model, posicionamento e alinhamento.
